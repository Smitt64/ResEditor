# Пользовательские элементы ToolBox — редактор панелей

Инструкция по созданию своих элементов панели инструментов (ToolBox)
для редактора панелей (PANEL/BSCROL/SCROL/LSCROL). Элементы описываются
json-файлами на диске — пересборка приложения не требуется. Файлы
подхватываются при открытии нового окна редактора панели.

## Куда класть файлы

| Каталог | Назначение |
|---|---|
| `%APPDATA%\<приложение>\toolbox\panels\` | Личные элементы пользователя |
| `<рабочий каталог>\reseditor\toolbox\panels\` | Элементы «проекта»/отладки |
| `<каталог программы>\reseditor\toolbox\panels\` | Поставляются с инсталлятором |

## Структура файла

```json
{
    "groups": [
        { "id": 100, "title": "Мои элементы" }
    ],

    "templates": [
        {
            "alias": "Заголовок панели",
            "icon": "theme:EditDocument",
            "tooltip": "Статический текст",
            "mimetype": "application/toolboxitem",
            "groups": [100],
            "mimedata": {
                "items": [ { ... } ]
            }
        }
    ]
}
```

### groups — объявление групп

- `id` — число, локально в рамках файла;
- `title` — название группы в ToolBox.

Группа с уже существующим `title` переиспользуется — так элементы можно
класть во встроенные группы: **«Элементы отображения»**,
**«Элементы ввода (FET поля)»**, **«Кнопки»**,
**«Cтатический текст (FVT поля)»**, **«Контейнеры»**, **«Псевдографика»**.

### templates — элементы

| Поле | Тип | Описание |
|---|---|---|
| `alias` | строка | Название элемента в списке ToolBox |
| `icon` | строка | Иконка: `theme:Имя`, qrc (`":/img/..."`), относительный путь (рядом с json) или абсолютный |
| `tooltip` | строка | Всплывающая подсказка |
| `mimetype` | строка | Всегда `application/toolboxitem` |
| `groups` | массив чисел | id групп |
| `mimedata` | объект | `{ "items": [ ... ] }` — элементы, вставляемые на панель |

## mimedata.items — элементы панели

Каждый элемент:

```json
{
    "class": "ControlItem",
    "parent": "",
    "uuid": "{a1b2c3d4-1111-4000-8000-000000000001}",
    "properties": [
        { "property": "point", "value": [0, 0] },
        { "property": "size",  "value": [7, 1] },
        { "property": "fieldType", "value": 1 },
        { "property": "dataType",  "value": 7 }
    ]
}
```

| Поле | Описание |
|---|---|
| `class` | Класс элемента: `TextItem`, `ControlItem`, `BorderItem`, `ContainerItem` |
| `parent` | Пусто — верхний уровень панели |
| `uuid` | Уникальный GUID элемента (любой; при вставке заменяется на свежий) |
| `properties` | Свойства в виде пар `property`/`value`. Координаты и размеры — в **ячейках** панели: `point` = `[x, y]`, `size` = `[ширина, высота]` |

Свойства применяются по имени к свойствам элемента; неизвестные имена
игнорируются. Указывать нужно только отличающиеся от умолчаний свойства.

### TextItem — статический текст

| Свойство | Тип | Описание |
|---|---|---|
| `point` | `[x, y]` | Позиция (ячейки) |
| `size` | `[w, h]` | Размер (ячейки) |
| `text` | строка | Текст (для псевдографики — символы рамок: `"─"`, `"│"`, `"├─"` и т.п.) |

### ControlItem — поле ввода / кнопка

| Свойство | Тип | Описание |
|---|---|---|
| `point` | `[x, y]` | Позиция (ячейки) |
| `size` | `[w, h]` | Размер (ячейки) |
| `fieldType` | число | Тип поля (таблица ниже) |
| `dataType` | число | Тип значения (таблица ниже) |
| `dataLength` | число | Длина данных в символах |
| `signs` | число | Знаков после запятой |
| `controlName` | строка | Наименование поля |
| `controlName2` | строка | Доп. имя/текст |
| `valueTemplate` | строка | Шаблон значения |
| `toolTip` | строка | Подсказка |
| `controlStyle` | число | Цветовой стиль (таблица ниже) |
| `controlGroup` | число | Группа (для radio-кнопок) |
| `helpPage` | число | Страница помощи |
| `controlFlags` | число | Доп. признаки, битовая маска (таблица ниже) |

#### fieldType — тип поля

| Значение | Константа | Описание |
|---|---|---|
| `1` | FET | Редактируемое поле |
| `2` | FBT | Кнопка |
| `3` | FBS | Кнопка с тенью |
| `4` | FWR | Редактируемое поле многострочное |
| `5` | FVT | Нередактируемое поле |
| `6` | FSP | Subpanel |
| `7` | FCL | Cluster (CheckBox / RadioButton) |
| `8` | FVW | Многострочное нередактируемое |

#### dataType — тип значения

| Значение | Константа | | Значение | Константа |
|---|---|---|---|---|
| `0` | INT16 | | `13` | UCHAR |
| `1` | INT32 | | `14` | LMONEY |
| `2` | FLOAT | | `15` | LMONEYR |
| `3` | FLOATG | | `16` | MONEYR |
| `4` | DOUBLE | | `17` | LDOUBLE |
| `5` | DOUBLEG | | `18` | NUMSTR |
| `6` | MONEY | | `19` | DECIMAL |
| `7` | STRING | | `25` | NUMERIC |
| `8` | SNR | | `26` | INT64 |
| `9` | DATE | | `27` | PICTURE (изображение) |
| `10` | TIME | | | |
| `11` | SHTM (краткое время) | | | |
| `12` | CHAR | | | |

#### controlStyle — цветовой стиль

| Значение | Константа | Описание |
|---|---|---|
| `-1` | MainStyle | Основной стиль панели |
| `0` | SMES | Стиль сообщений |
| `1` | RMES | Стиль аварийных сообщений |
| `2` | SHLP | Стиль помощи |
| `3` | SMEN | Стиль меню |
| `4` | SCOM | Основной стиль |
| `5` | SBCM | Стиль с яркой рамкой |
| `6` | SCRL | Стиль справочных скролингов |

#### controlFlags — доп. признаки (битовая маска, hex)

| Значение | Константа | Описание |
|---|---|---|
| `0x00000004` | RF_REQUIRED | Обязательное поле |
| `0x00000008` | RF_NEGATIVE | Допускается отрицательное значение |
| `0x00000100` | RF_3STATE | CheckBox с тремя состояниями (вместе с RF_CHECKBOX) |
| `0x00001000` | RF_ELIPSBTN | Кнопка «...» (вызов справочника) |
| `0x00002000` | RF_DOWNBTN | Кнопка выпадающего списка |
| `0x00004000` | RF_EMPTY | Допускается пустое значение |
| `0x00008000` | RF_TRIMZEROS | Обрезать незначащие нули |
| `0x00010000` | RF_GROUP | Начало группы (radio) |
| `0x00020000` | RF_CHECKBOX | Флажок |
| `0x00040000` | RF_RADIO | Переключатель |
| `0x00080000` | RF_PASSWORD | Поле пароля |
| `0x00100000` | RF_PROGRESS | Индикатор прогресса |
| `0x00200000` | RF_TREEITEM | Элемент дерева |
| `0x00400000` | RF_DYNLEN | Динамическая длина |
| `0x00800000` | RF_INDIC | Индикатор |
| `0x01000000` | RF_ASTEXT | Как текст |
| `0x02000000` | RF_NOEDGE | Без рамки |
| `0x04000000` | RF_BLOCKHIDE | Не скрывать блок |
| `0x08000000` | RF_FLAT | Плоский вид |
| `0x10000000` | RF_GROUPING | Группировка |
| `0x20000000` | RF_NOTABSTOP | Не участвует в обходе по Tab |
| `0x40000000` | RF_NOCHECK | Без проверки |
| `0x80000000` | RF_ANSI_STRING | ANSI-строка |

В json значения пишутся десятичными: например RF_CHECKBOX =
`131072`, RF_CHECKBOX + RF_3STATE = `131072 + 256 = 131328`.

### BorderItem — рамка

| Свойство | Тип | Описание |
|---|---|---|
| `point` | `[x, y]` | Позиция (ячейки) |
| `size` | `[w, h]` | Размер (ячейки) |
| `borderStyle` | число | Стиль рамки: `0` — нет, `1` — двойная, `2` — одинарная, `3` — сплошная, `4` — комбинированная 1, `5` — комбинированная 2 |

## Составные элементы

Один элемент ToolBox может вставлять **несколько** объектов панели —
например, метку и поле ввода (так устроены встроенные
«Переключатель»/«Флажок»):

```json
"mimedata": {
    "items": [
        { "class": "TextItem", "parent": "", "uuid": "{...1}",
          "properties": [ ... ] },
        { "class": "ControlItem", "parent": "", "uuid": "{...2}",
          "properties": [ ... ] }
    ]
}
```

Позиции относительны: при вставке весь набор сдвигается так, чтобы его
левый верхний угол оказался в точке сброса.

## Как получить готовый json (простой способ)

Соберите элемент(ы) мышью прямо на панели, выделите их и нажмите
**Ctrl+C** — в буфер обмена попадёт структура `{ "items": [ ... ] }` в
том же формате. В отладочной сборке она доступна и как обычный текст —
остаётся вставить в `mimedata` своего элемента.

## Полный пример

См. поставляемый файл `reseditor/toolbox/panels/example_toolbox.json`
(в исходниках: `rsbaseeditor/toolbox/panels/example_toolbox.json`).

## Замечания

- Невалидный json пропускается, предупреждение пишется в лог.
- Встроенные элементы переопределить нельзя — только добавлять свои.
- В уже открытом окне редактора список не обновляется — откройте панель
  заново.
