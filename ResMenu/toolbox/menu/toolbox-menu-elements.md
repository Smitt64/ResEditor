# Пользовательские элементы ToolBox — редактор меню

Инструкция по созданию своих элементов панели инструментов (ToolBox)
для редактора меню. Элементы описываются json-файлами на диске —
пересборка приложения не требуется. Файлы подхватываются при открытии
нового окна редактора меню.

## Куда класть файлы

Файл `*.json` с элементами помещается в один из каталогов
(сканируются все три, элементы просто добавляются):

| Каталог | Назначение |
|---|---|
| `%APPDATA%\<приложение>\toolbox\menu\` | Личные элементы пользователя |
| `<рабочий каталог>\reseditor\toolbox\menu\` | Элементы «проекта»/отладки |
| `<каталог программы>\reseditor\toolbox\menu\` | Поставляются с инсталлятором |

## Структура файла

```json
{
    "groups": [
        { "id": 100, "title": "Мои элементы" }
    ],

    "templates": [
        {
            "alias": "Моя команда",
            "icon": "theme:Execute",
            "tooltip": "Подсказка в списке ToolBox",
            "mimetype": "application/x-menueditor-template",
            "groups": [100],
            "mimedata": {
                "type": "item",
                "action": { ... }
            }
        }
    ]
}
```

### groups — объявление групп

- `id` — число, локально в рамках файла (на него ссылаются элементы);
- `title` — название группы в ToolBox.

Если группа с таким `title` уже существует (встроенная или из другого
файла) — элемент попадёт в неё, дубликат группы не создаётся. Встроенные
группы редактора меню: **«Стандартные команды»** и **«Операции»**.

### templates — элементы

| Поле | Тип | Описание |
|---|---|---|
| `alias` | строка | Название элемента в списке ToolBox |
| `icon` | строка | Иконка элемента (см. ниже) |
| `tooltip` | строка | Всплывающая подсказка |
| `mimetype` | строка | Всегда `application/x-menueditor-template` |
| `groups` | массив чисел | id групп, в которые попадёт элемент |
| `mimedata` | объект | Содержимое, вставляемое в меню при перетаскивании |

### icon — способы задания иконки

| Вид | Пример | Описание |
|---|---|---|
| `theme:Имя` | `"theme:Execute"` | Иконка из иконочной темы приложения |
| qrc-ресурс | `":/res/ActionEdit.svg"` | Встроенный ресурс (только существующие) |
| Относительный путь | `"icons/my.svg"` | Файл рядом с json (можно положить свой svg/png) |
| Абсолютный путь | `"D:/icons/my.svg"` | Любой файл на диске |

## mimedata — что вставляется в меню

### Обычный пункт

```json
"mimedata": {
    "type": "item",
    "action": {
        "text": "Моя команда",
        "statusTip": "Строка состояния",
        "helpId": 0,
        "commandId": 0,
        "cmdEx": 0,
        "iconID": 0,
        "flags": 0
    }
}
```

Поля `action`:

| Поле | Тип | Описание |
|---|---|---|
| `text` | строка | Заголовок пункта. `&X` задаёт мнемонику (подчёркнутую букву): `"&Действия"` |
| `enabled` | bool | Доступен ли пункт (по умолчанию `true`, можно не указывать) |
| `visible` | bool | Виден ли пункт (по умолчанию `true`, можно не указывать) |
| `shortcut` | строка | Сочетание клавиш в формате Qt (`"Ctrl+M"`, `"F6"`). Задавать **не нужно**, если задан `commandId` — сочетание выводится из кода команды автоматически. Имеет смысл только для пользовательских команд без кода в таблице клавиш |
| `statusTip` | строка | Текст в строке состояния (поле `par` формата меню) |
| `toolTip` | строка | Всплывающая подсказка |
| `helpId` | число | Идентификатор страницы помощи (0–65535, 0 — нет) |
| `commandId` | число | Код команды. Известные коды — см. `json/KeyCodes.json` и диалог выбора команды в редакторе; 0 — без кода |
| `cmdEx` | число | Расширенные флаги команды (модификаторы Alt/Shift/Ctrl в старом формате); обычно `0` |
| `iconID` | число | Идентификатор иконки из ресурсной DLL (подбирается диалогом выбора иконки в ленте редактора); `0` — без иконки |
| `flags` | число | Битовая маска размещения пункта (см. ниже) |

#### flags — битовая маска

| Значение | Константа | Описание |
|---|---|---|
| `1` | `dFMENU_TOOLBAR` | Пункт отображается на панели инструментов |
| `2` | `dFMENU_CONTEXT` | Пункт попадает в контекстное меню |
| `4` | `DISINEMPTYSCROL` | Пункт недоступен в пустом скроллинге |

Значения складываются: `5` = на toolbar + недоступен в пустом скроллинге.

### Разделитель

```json
"mimedata": { "type": "separator" }
```

### Подменю

```json
"mimedata": {
    "type": "submenu",
    "action": {
        "text": "Отчёты",
        "statusTip": "",
        "helpId": 0
    },
    "items": [
        { "type": "item", "action": { ... } },
        { "type": "separator" },
        { "type": "submenu", "action": { ... }, "items": [ ... ] }
    ]
}
```

`items` — вложенные элементы того же формата (вложенность не ограничена).

## Полный пример

См. поставляемый файл `reseditor/toolbox/menu/example_toolbox.json`
(в исходниках: `ResMenu/toolbox/menu/example_toolbox.json`) — он создаёт
группу «Мои элементы» и добавляет пункт во встроенную группу
«Стандартные команды».

## Коды стандартных команд

Встроенные элементы ToolBox заполнены реальными кодами команд — их можно
использовать как образец и как источник сочетаний клавиш (сочетание
выводится из кода автоматически, поле `shortcut` не нужно):

| Пункт | `commandId` | Сочетание |
|---|---|---|
| Редактировать | 13 | Enter |
| Просмотр | 10 | Ctrl+Enter |
| Выполнение операции | 316 | F2 |
| Поиск | 318 | F4 |
| Фильтр | 319 | F5 |
| Шаги операции | 320 | F6 |
| Печать | 321 | F7 |
| Удалить | 322 | F8 |
| Новая строка / Сохранить | 323 | F9 |
| Просмотр истории | 291 | Alt+H |
| Категории | 380 | Alt+5 |

У пунктов «Примечания», «Функция пользователя» и «Счета» стандартного кода
нет (`commandId: 0`) — «Функция пользователя» это макро-вызов, код ей
назначает сам пользовательский ресурс.

Полный список кодов клавиш — `json/KeyCodes.json` (подгружается в диалог
выбора команды в редакторе).

## Замечания

- Невалидный json пропускается, предупреждение пишется в лог.
- Встроенные элементы переопределить нельзя — только добавлять свои.
- В уже открытом окне редактора список не обновляется — откройте меню
  заново.
